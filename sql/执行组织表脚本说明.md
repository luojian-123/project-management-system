# 组织管理表：先建表，再按需修复

按顺序执行下面两步（在 **pms** 库下）。

## 1. 先执行建表脚本

创建 `pm_company`、`pm_dept`（若已存在则跳过）。

**命令行：**
```bash
cd D:\PMS系统代码\sql
mysql -u root -p pms < V3_org_company_dept.sql
```
（提示时输入 MySQL 密码）

**或用客户端：**  
用 Navicat / DBeaver 等连接 pms，打开并执行 `V3_org_company_dept.sql`。

---

## 2. 再按需执行修复脚本

若组织管理里点「刷新」仍报错：`Unknown column 'company_id'`，说明 `pm_dept` 是旧表，缺少 `company_id` 列，需要执行：

**命令行：**
```bash
mysql -u root -p pms < V3_org_fix_pm_dept.sql
```

**或用客户端：**  
打开并执行 `V3_org_fix_pm_dept.sql`。

若执行时报 **Duplicate column name 'company_id'**，说明列已存在，可忽略，直接再点一次刷新即可。

---

## 一键执行（PowerShell，需输入一次密码）

在 `D:\PMS系统代码\sql` 目录下执行：

```powershell
$env:MYSQL_PWD = Read-Host "输入 MySQL 密码" -AsSecureString | ConvertFrom-SecureString -AsPlainText
mysql -u root -p"$env:MYSQL_PWD" pms < V3_org_company_dept.sql
mysql -u root -p"$env:MYSQL_PWD" pms < V3_org_fix_pm_dept.sql
Remove-Item Env:MYSQL_PWD -ErrorAction SilentlyContinue
Write-Host "完成。"
```

（第二句若报 Duplicate column 可忽略。）
