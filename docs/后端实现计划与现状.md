## 二、当前已实现模块

### 1. 工程与配置
- **PmsApplication**：启动类，`@MapperScan("com.pms.mapper")`
- **application.yml**：数据源（MySQL pms）、MyBatis、JWT、端口 8080、context-path `/api`
- **SecurityConfig**：关闭 CSRF、CORS 放行、JWT 过滤器、登录/注册放行
- **InitDataRunner**：首次启动创建 admin 用户（密码 123456）并绑定 ADMIN 角色与全部菜单

### 2. 认证与权限
- **JwtUtil**：生成/解析 Token，从请求头 `Authorization: Bearer <token>` 取 userId
- **JwtAuthFilter**：校验 Token，将 userId 放入 request 属性，供业务获取当前用户
- **AuthController**：`POST /auth/login`、`GET /auth/info`、`POST /auth/register`
- **AuthService**：按用户名查用户、校验密码、生成菜单树（按用户角色）

### 3. 业务模块与接口

| 模块 | 路径前缀 | 主要接口 |
|------|----------|----------|
| 项目 | `/project` | 分页、详情、新增、修改、删除 |
| 任务 | `/task` | 按项目列表/树、详情、保存、依赖、删除 |
| 待办 | `/todo` | 分页、详情、保存、删除 |
| 成本 | `/cost` | 按项目分页、详情、保存、删除 |
| 问题 | `/issue` | 分页、详情、保存、删除 |
| 变更 | `/change` | 分页、详情、保存、删除 |
| 风险 | `/risk` | 分页、详情、保存、删除 |
| 字典 | `/sys/dict` | 类型列表、按类型查项、类型/项保存、项删除 |
| 系统配置 | `/sys/config` | 审批流及节点、表单及字段、页签列表与保存 |

### 4. 数据层
- **Entity**：与表一一对应（sys_*、pm_*）
- **Mapper**：接口 + 对应 `resources/mapper/*.xml`，下划线转驼峰已开启
- **Service**：调用 Mapper，部分使用 `WebConfig.getCurrentUserId()` 取当前用户

## 三、建议补充（可选）

1. **全局异常处理**：`@RestControllerAdvice` 捕获异常，返回统一 `Result.fail(message)`，避免 500 直接抛栈。
2. **参数校验**：关键 DTO 使用 `@NotNull`、`@NotBlank` 等，配合 `@Valid`。
3. **接口文档**：集成 SpringDoc 或 Swagger，便于前后端联调。

## 四、本地运行方式

确保已安装 **JDK 17** 和 **Maven**，且 MySQL 已创建 pms 库并执行过 `sql/schema.sql`。

```bash
cd backend
mvn spring-boot:run
```

或使用 IDE 运行 `com.pms.PmsApplication`。

- 接口基地址：`http://localhost:8080/api`
- 默认管理员：用户名 `admin`，密码 `123456`
