# 项目管理系统 - 产品需求文档（PRD）

**版本**: v1.0  
**日期**: 2025-03-03  
**状态**: 初稿

---

## 一、产品概述

### 1.1 产品定位
面向企业/团队的项目全生命周期管理系统，覆盖个人待办、项目与任务、问题、风险、审批及系统配置，支持表单/列表可配置与数据字典管理。

### 1.2 目标用户
- 项目成员：查看待办、执行任务、上报问题与风险
- 项目经理：管理项目、任务、问题、风险及审批
- 系统管理员：权限、审批流、系统配置（表单/列表/页签/数据字典）

### 1.3 核心价值
- 统一入口：待办、项目、问题、风险、审批一站式处理
- 可视化：甘特图展示项目与任务进度
- 可配置：表单字段、列表字段、页签、数据字典由配置驱动，减少二次开发

## 三、模块详细需求

### 3.1 个人待办

**功能描述**  
集中展示当前用户需要处理的待办事项，来源包括：分配给自己的任务、需要处理的问题、待自己审批的流程。

**功能点**
- 待办列表：分页展示，支持按类型（任务/问题/审批）、状态、时间筛选
- 待办详情：跳转到对应业务模块的详情或处理页
- 快捷处理：支持在待办列表中直接“完成”“通过/驳回”等操作（视业务支持）

**字段**
- 待办类型、标题、来源业务 ID、创建时间、截止时间、状态、处理链接

---

### 3.2 项目管理

**功能描述**  
管理项目基本信息，并在项目下管理任务，通过甘特图展示任务与进度。

**3.2.1 项目**
- 项目列表：分页、搜索（名称/编码）、状态筛选
- 项目新增/编辑：名称、编码、负责人、开始/结束时间、状态、描述等（具体字段可由系统配置扩展）
- 项目详情：基本信息 + 页签（任务列表、问题列表、风险列表等，页签可配置）

**3.2.2 任务管理**
- 任务列表：支持按项目、执行人、状态筛选；支持树形结构（父子任务）
- 任务新增/编辑：所属项目、父任务、任务名称、负责人、开始/结束时间、进度、优先级、状态、描述等
- 任务状态：未开始、进行中、已完成、已关闭等（可配置字典）

**3.2.3 甘特图**
- 以项目或任务为维度展示甘特图
- 展示任务名称、负责人、开始/结束时间、进度条、依赖关系（可选）
- 支持拖拽调整时间、缩放时间轴（日/周/月）

---

### 3.3 问题管理

**功能描述**  
对项目/任务中发现的问题进行登记、分配、跟踪与关闭。

**功能点**
- 问题列表：分页、按项目、状态、严重程度、负责人筛选
- 问题新增/编辑：关联项目（可选关联任务）、标题、描述、严重程度、优先级、负责人、状态、截止时间等
- 问题状态流转：如 待处理→处理中→已解决→已关闭（可配置）
- 问题详情：基本信息 + 评论/历史（可选）

---

### 3.4 风险管理

**功能描述**  
对项目风险进行识别、评估与应对跟踪。

**功能点**
- 风险列表：分页、按项目、状态、风险等级筛选
- 风险登记/编辑：关联项目、风险描述、风险等级、发生概率、影响程度、应对措施、负责人、状态等
- 风险状态：识别中、应对中、已缓解、已关闭等（可配置）
- 风险详情：同问题，可带备注与历史

---

### 3.5 权限管理

**功能描述**  
管理用户、角色、菜单及数据权限，支撑登录与各模块的访问控制。

**功能点**
- 用户管理：用户列表、新增/编辑用户、启用/禁用、重置密码；关联角色
- 角色管理：角色列表、新增/编辑角色、分配菜单权限、分配数据权限（如本部门、本人）
- 菜单管理：树形菜单、新增/编辑/删除、排序、图标、路由、权限标识
- 数据权限：按角色配置数据范围（全部/本部门/本部门及下级/仅本人等），在业务查询时过滤

---

### 3.6 审批管理

**功能描述**  
支持可配置的审批流程，以及审批实例的发起、审批、查询。

**功能点**
- 流程定义：审批类型（如请假、报销、项目立项等）、名称、适用业务、审批节点（顺序/会签等）、节点审批人（角色/用户）
- 发起审批：在业务侧选择审批类型发起，生成审批单与流程实例
- 待我审批：当前用户待审批列表，支持通过/驳回/转交
- 我已审批：历史审批记录
- 审批记录：流程实例的节点与审批意见列表

**数据**  
审批单主表、流程实例、流程节点实例、审批意见

---

### 3.7 系统配置管理

**功能描述**  
通过配置驱动表单、列表、页签与数据字典，减少硬编码。

**3.7.1 表单字段配置**
- 按“业务类型”（如项目、任务、问题、风险、审批单等）配置表单字段
- 字段属性：字段编码、名称、类型（文本/数字/日期/下拉/多选等）、是否必填、顺序、是否显示、默认值、关联数据字典等
- 支持新增/修改/删除/排序

**3.7.2 列表字段配置**
- 按业务类型配置列表展示列：字段、列名、宽度、是否排序、是否固定等
- 与表单字段可复用同一套字段定义或单独配置

**3.7.3 页签配置**
- 配置业务详情页的页签：如项目详情下的“任务”“问题”“风险”页签
- 属性：页签编码、名称、关联业务类型、关联列表/组件、顺序

**3.7.4 数据字典**
- 字典类型：如 任务状态、问题严重程度、风险等级、审批状态等
- 字典项：类型下具体选项，含编码、名称、排序、状态
- 表单/列表中的下拉、多选等可关联字典类型

## 四、非功能需求

- **性能**：列表分页，单页建议 20/50 条；甘特图数据量较大时支持按项目/时间范围加载
- **安全**：接口鉴权（如 JWT）、密码加密、操作日志（可选）
- **兼容**：前端支持现代浏览器；后端 Java 8+，Spring Boot 2.x/3.x
- **扩展**：系统配置模块支持后续新增业务类型与字段，便于扩展

## 六、附录：与系统配置的联动说明

- 项目、任务、问题、风险、审批单等“业务类型”在系统配置中注册后，即可为其配置表单字段、列表字段。
- 详情页的页签通过“页签配置”绑定到业务类型与对应列表/组件，实现详情页 Tab 可配置。
- 所有下拉、单选等需枚举的地方，均通过“数据字典”配置并关联到表单字段，保证一处维护、全局生效。
